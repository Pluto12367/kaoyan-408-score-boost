# 管理员题库文档导入设计

## 1. 背景

当前项目已经部署在腾讯云轻量服务器上，管理员可以通过网站完成账号和邀请码管理，但题库导入仍主要依赖命令行或结构化文本。短期内，管理员导入的资料数量较少；后期可能需要导入整本 PDF 资料。资料既可能是文字版 PDF，也可能是扫描版 PDF，并且可能包含双栏排版、公式、表格和题图。

本设计将 PDF、Excel 和 CSV 统一为一套“上传、异步解析、管理员审核、确认入库”的工作流。任何自动识别结果都只是候选内容，未经管理员确认不得进入正式题库。

本设计细化并替代 `2026-07-29-domestic-cloud-invite-and-question-import-design.md` 中第 6 节的题库导入方案；其他部署、注册和账号管理设计继续有效。

## 2. 已确认的产品决策

- 只有管理员可以上传、审核和导入题目。
- 第一版支持 PDF、`.xlsx` 和 `.csv`；不支持旧版 `.xls`。
- 同时支持文字版 PDF 和扫描版 PDF。
- 优先保证识别质量，可以使用付费 OCR 或文档解析服务。
- 所有解析出的题目都必须经过管理员确认。
- 正确题目可以先行入库，失败或有问题的题目继续留在批次中修正。
- 重复题默认跳过；管理员可以选择创建新版本，旧版本和历史答题记录必须保留。
- 第一版支持公式、题图和原始页对照。
- 原始上传文件默认保留 30 天；正式题目需要的局部图片永久保留。
- 来源为必填项，上传前必须确认拥有相应使用或导入权限。
- 生产服务器继续使用现有 2 核 CPU、2GB 内存、40GB 系统盘，不在该服务器上运行大型本地 OCR 模型。

## 3. 目标与非目标

### 3.1 目标

- 管理员无需登录服务器或配置数据库连接即可导入题库。
- 小型表格和整本 PDF 都使用一致、可恢复的后台任务。
- 自动识别错误被显式暴露，不静默猜测或覆盖正式数据。
- 管理员可以一边审核、一边分批导入正确题目。
- 重复检测、版本管理和资源保留不会破坏学生历史记录。
- 导入任务的资源消耗不得明显影响学生登录、答题和报告查询。
- 解析提供商可以替换，业务数据模型不绑定单一云服务。

### 3.2 非目标

- 不允许学生或教师自行导入资料。
- 不承诺自动识别结果可以免审核直接发布。
- 第一版不提供通用 PDF 编辑器、复杂图片标注工具或多人实时协同审核。
- 第一版不在 2GB 生产服务器上自托管 MinerU、PaddleOCR、Docling 等模型。
- 第一版不支持 Word、PPT、EPUB、ZIP 或旧版 `.xls`。
- 第一版不自动判断资料版权是否合法；系统只要求管理员填写来源并留下权限确认记录。

## 4. 开源与成熟方案参考

设计参考以下四个方向，仅借鉴流程和数据结构，不复制其源代码：

1. [MinerU](https://github.com/opendatalab/MinerU) 及其[输出文件说明](https://opendatalab.github.io/MinerU/reference/output_files/)：参考按页输出结构化文本、公式、图片、坐标和中间产物的方式，以及异步处理大文档的思路。生产环境优先使用其远程解析能力，不在当前服务器部署完整模型。
2. [PP-StructureV3](https://www.paddleocr.ai/main/en/version3.x/algorithm/PP-StructureV3/PP-StructureV3.html)：参考版面、阅读顺序、表格、公式和图像区域的统一表达。它是未来更换解析提供商或离线批处理时的候选方案。
3. [Docling](https://github.com/docling-project/docling)：参考统一文档模型和多格式解析适配层。由于其本地推理依赖和资源占用，不作为当前 2GB 服务器的生产组件。
4. [Moodle 题目导入](https://docs.moodle.org/502/en/Import_questions)：参考“选择格式和文件、展示错误、预览、确认”的管理员导入流程，以及媒体资源随题目进入题库的处理方向。

PDF 默认使用 MinerU 远程解析服务。若某页解析失败、文本覆盖率过低或关键区域缺失，则允许通过提供商适配层将该页送至[腾讯云 OCR](https://cloud.tencent.com/document/product/866/86721)重新识别。回退规则必须基于可配置的质量信号，不能因一次普通字段校验失败就重复计费。

在正式开发 PDF 能力前，必须使用三份有合法使用权的样本做小规模基准测试，再锁定具体 API 版本、质量阈值和成本上限。

## 5. 总体架构

```text
管理员上传 PDF / XLSX / CSV
            |
            v
       私有文件存储
            |
            v
       导入批次与任务队列
            |
     +------+------+
     |             |
     v             v
表格解析器      PDF 提供商适配器
                  |
           MinerU 默认解析
                  |
        低质量页 -> 腾讯云 OCR 回退
     |             |
     +------+------+
            v
       统一文档块模型
            |
            v
     题目结构化与字段校验
            |
            v
      待审核题目与资源
            |
            v
 管理员对照审核、查重、分批确认
            |
            v
     正式题目、版本与审计记录
```

系统由以下逻辑组件组成：

1. **管理员导入页面**：负责上传、查看进度、审核和确认入库。
2. **导入批次服务**：维护批次状态、任务拆分、重试、幂等和统计。
3. **私有文件存储**：保存原始文件、解析中间产物、整页截图和永久题图。
4. **解析提供商适配器**：屏蔽 MinerU、腾讯云 OCR 或未来其他解析服务之间的差异。
5. **题目结构化服务**：将页面块转换为候选题目，标记不确定字段，不直接写入正式题库。
6. **审核与入库服务**：执行字段校验、重复检测、版本创建、资源提升和审计记录。

## 6. 文件存储和任务拆分

### 6.1 私有存储

第一版使用服务器上的专用 Docker 数据卷，目录不经 Nginx 静态暴露。所有下载和预览都通过需要管理员身份的后端接口完成。存储接口应保持可替换，以便后期迁移到腾讯云 COS。

文件分为三类：

- **临时原件**：原始 PDF、XLSX、CSV，默认 30 天后删除。
- **临时解析产物**：原始页面截图、提供商返回文件和 OCR 中间结果，默认 30 天后删除。
- **永久题目资源**：正式题目版本引用的局部图片、图表或其他必要资源，随题目版本长期保留。

临时资源转为永久资源时，应复制或提升到独立存储键，不得让正式题目继续引用会到期的临时路径。

### 6.2 上传和拆分

- 上传采用流式写盘和文件摘要计算，不将整本 PDF 读入内存。
- PDF 按页数和文件大小拆分为子任务。默认每个远程解析任务不超过 200 页，具体上限由提供商配置决定。
- 大于单任务限制的整本资料仍属于同一个导入批次，管理员只看到一个总体进度。
- Excel 和 CSV 按固定行数分块解析，但审核和确认仍以同一批次呈现。
- 文件大小、页数、行数和批次占用配额均为服务器配置，不写死在前端。
- 当临时文件占用达到安全阈值或磁盘使用率超过预警线时，系统暂停新上传，不影响已有学生功能。

### 6.3 任务优先级

- 学生登录、答题和管理员日常操作优先于导入后台任务。
- 当前 2GB 服务器默认只运行一个文档解析调度任务和一个轻量结构化任务。
- 外部解析任务通过轮询或回调获取结果；轮询必须退避，不能持续占用应用线程。
- 服务重启后从数据库状态恢复任务，不依赖进程内队列作为唯一事实来源。

## 7. 状态模型

### 7.1 批次状态

```text
uploaded -> queued -> parsing -> review -> partially_imported -> completed
                |         |          |
                |         |          +-> review
                |         +-> parsing_partial_failure
                +-> failed

任意非终态 -> cancelled
已完成且临时资源到期 -> expired
```

状态含义：

- `uploaded`：文件已安全落盘，尚未建立解析任务。
- `queued`：任务已建立，等待执行。
- `parsing`：至少一个子任务正在解析或结构化。
- `parsing_partial_failure`：部分子任务失败，但已有候选题可以审核。
- `review`：存在可审核题目，解析任务已达到可展示状态。
- `partially_imported`：部分题目已正式入库，仍有题目待处理。
- `completed`：所有候选题均已通过、跳过或明确忽略。
- `failed`：没有可用结果，且自动重试已耗尽。
- `cancelled`：管理员取消后不再创建新任务；已产生的候选结果保留到清理期限。
- `expired`：临时原件和中间产物已清理。

批次状态是子任务和候选题状态的汇总，不由前端直接修改。

### 7.2 子任务状态

子任务使用 `pending`、`submitted`、`processing`、`succeeded`、`retry_wait`、`failed`、`cancelled`。每个子任务记录页码或行号范围、提供商任务 ID、尝试次数、下次重试时间、错误类型、处理耗时和费用信息。

自动重试仅适用于超时、限流和临时服务错误。文件损坏、格式不支持、权限错误和稳定复现的解析错误直接转为人工处理。

### 7.3 候选题状态

候选题使用：

- `pending_review`
- `needs_edit`
- `duplicate_suspected`
- `approved`
- `ignored`
- `parse_failed`
- `imported`

管理员可以多次分批确认。已入库候选题不可再次入库，重复确认请求返回原结果。

## 8. 核心数据模型

具体表名可在实施计划中结合现有 Prisma 模型调整，但必须保留以下职责边界。

### 8.1 `QuestionImportBatch`

记录：

- 上传管理员、文件名、文件摘要、文件类型和存储键。
- 资料名称、来源、年份、默认科目、章节和知识点。
- 权限确认值、确认时间和确认管理员。
- 批次状态、总页数或总行数、各状态题目数量。
- 解析提供商、预计费用、实际费用和处理时间。
- 创建、开始、完成和临时文件到期时间。
- 幂等键及最后一次错误摘要。

来源和权限确认必须在建立批次前通过校验。审计记录保存确认事实，但不保存上传文件全文。

### 8.2 `QuestionImportJob`

记录：

- 所属批次和稳定的任务序号。
- 页码或行号起止范围。
- 解析提供商及外部任务 ID。
- 状态、尝试次数、质量信号、费用和耗时。
- 原始结果存储键、错误分类和安全化错误摘要。

同一批次、任务序号和尝试版本必须具有唯一约束，防止服务重启后重复提交。

### 8.3 `QuestionImportCandidate`

记录：

- 题干、选项、答案、解析、题型、难度、科目、章节、知识点和建议时长。
- 来源批次、来源页码或行号、页面坐标和阅读顺序。
- 公式的规范化表示、题目资源引用和原始片段引用。
- 各字段置信度、警告代码、人工修改痕迹和审核状态。
- 内容指纹、疑似重复匹配结果和管理员选择的入库策略。
- 审核人、审核时间、正式题目 ID 和正式版本 ID。

自动结构化无法确定答案、选项归属或题目边界时，应留下空值和警告，不得用模型猜测出的内容冒充确定结果。

### 8.4 `QuestionAsset`

记录：

- 临时或永久存储键、媒体类型、文件摘要、尺寸和字节数。
- 来源批次、来源页码、裁剪坐标。
- 所属候选题或正式题目版本。
- 保留级别、到期时间和删除时间。

同一文件摘要可以复用存储对象，但引用关系必须独立。清理任务只删除没有有效引用的对象。

### 8.5 正式题目版本

正式题目使用稳定题目 ID 表示逻辑上的同一道题，每次内容更新创建不可变版本。版本至少记录：

- 完整题目内容和资源引用。
- 来源、年份和内容指纹。
- 创建原因、来源导入批次、创建管理员和创建时间。
- 是否为当前启用版本。

学生作答记录固定引用作答时的版本 ID。新练习只选择当前启用版本。切换或恢复旧版本只改变当前版本指针，不重写历史作答。

## 9. 统一解析结果

PDF、XLSX 和 CSV 最终都转换成统一候选题结构。PDF 解析适配器输出至少包含：

- 页码、页面尺寸和阅读顺序。
- 文本块及坐标。
- 公式块及可用的 LaTeX 或结构化表示。
- 图片、表格和图表区域及对应资源。
- 提供商置信度和原始块标识。

表格解析器将每一行映射为相同的题目字段，并保留行号作为来源定位。模板至少包含：

- 科目
- 章节
- 知识点
- 题型
- 难度
- 题干
- 选项 A 至选项 D
- 正确答案
- 答案解析
- 来源
- 年份
- 建议答题时间（秒）

CSV 使用明确的编码检测和中文错误提示；导出的标准模板采用 UTF-8 BOM。XLSX 解析不得执行宏或公式。公式单元格有可用缓存值时读取缓存值，否则标记为待修改。

## 10. 题目结构化和质量标记

题目结构化服务负责：

- 根据题号、版面、字体块、选项标识和答案区间切分题目。
- 将跨页题干和解析关联到同一候选题。
- 关联题目附近的公式和图片。
- 识别缺少题干、答案、选项或解析等字段问题。
- 根据导入默认值和已有知识点字典进行字段映射。
- 为每个不确定字段生成机器可读警告代码。

低质量信号包括但不限于：

- 页面没有文本且没有合理的图像结果。
- 题号连续性明显中断。
- 选择题缺少选项或答案不在选项范围内。
- OCR 字符异常比例过高。
- 公式块丢失或图片引用不存在。
- 跨页合并存在多个可能归属。

低质量页可以触发腾讯云 OCR 回退。回退结果不得直接覆盖原结果；系统保留两个结果和选择依据，供后续调试和费用核对。

## 11. 重复检测和版本策略

### 11.1 内容指纹

系统对题干和选项进行规范化后生成确定性内容指纹。规范化仅处理不影响含义的差异，例如首尾空白、连续空格、全半角标点和选项标签格式；不得删除公式、数字、单位或图片引用。

完全相同的指纹结合科目和题型判定为确定重复，默认跳过。来源和年份用于展示和辅助判断，但不应让同一道题仅因来源写法不同就自动成为新题。

### 11.2 疑似重复

相似度检测用于找出题干高度相近但内容指纹不同的题目。阈值必须可配置，结果只标记为“疑似重复”，不能自动覆盖。

管理员可以选择：

- 跳过。
- 作为独立新题导入。
- 作为匹配题目的新版本导入。

选择“新版本”时必须展示旧版和新版差异，并保留原版本。

### 11.3 幂等

上传文件摘要用于提示重复上传，但管理员可以在确认后重新建立新批次。正式确认接口必须使用服务器生成的幂等键，并在数据库事务中完成：

1. 锁定待确认候选题。
2. 再次执行字段和重复状态校验。
3. 创建正式题目或新版本。
4. 提升永久资源。
5. 写入候选题、批次统计和审计记录。

网络重试或重复点击确认时，返回第一次成功的结果，不重复创建题目。

## 12. 管理员界面

### 12.1 新建导入

管理员选择 PDF、XLSX 或 CSV，填写资料名称、来源、年份、科目和可选章节，勾选权限确认后提交。PDF 可以选择页码范围；默认导入整份文件。

页面提供：

- XLSX 和 CSV 标准模板下载。
- 字段示例和常见错误说明。
- 最近一次导入设置自动带入。
- 简洁模式和可折叠的高级设置。

提交成功后立即返回批次页面，后台继续解析，管理员可以安全离开。

### 12.2 导入任务列表

列表显示：

- 状态和总体进度。
- 已识别、待审核、异常、疑似重复和已入库数量。
- 已处理页数或行数、处理耗时和预计剩余时间。
- 解析提供商、已知费用和费用是否仍为估算值。
- 创建时间、上传管理员和临时文件到期时间。

失败批次允许仅重试失败页或失败行，不要求重新上传整本资料。

### 12.3 对照审核

桌面端以左侧原始页面、右侧候选题表单为主：

- 左侧打开原始页并定位题目坐标。
- 右侧编辑题干、选项、答案、解析、题型、难度、科目和知识点。
- 公式使用可编辑的规范化表示并提供渲染预览。
- 图片支持裁剪、替换、删除或保留。
- 字段警告、缺失项、低置信度和疑似重复醒目标记。
- 支持筛选异常、疑似重复、未审核和已审核题目。
- 支持单题审核、无警告题目的批量通过和常用快捷键。
- 管理员编辑自动保存草稿。

批量通过仅作用于字段完整且没有阻断警告的题目。异常题必须单独处理或明确忽略。

### 12.4 确认入库

确认页展示：

- 新增题目数量。
- 默认跳过的重复题数量。
- 将创建新版本的题目数量。
- 被忽略、尚未处理和解析失败的题目数量。
- 将永久保留的资源数量和预计空间。

管理员确认后只处理当前选中的已审核题目。其他候选题继续保留，可在后续批次确认中处理。

## 13. API 边界

具体路由名称可以按现有 NestJS 模块命名调整，但职责应保持分离：

- `POST /admin/question-imports`：流式上传并创建批次。
- `GET /admin/question-imports`：查询批次列表。
- `GET /admin/question-imports/:id`：查询批次、任务和统计。
- `POST /admin/question-imports/:id/cancel`：取消尚未完成的任务。
- `POST /admin/question-imports/:id/retry`：重试指定失败任务。
- `GET /admin/question-imports/:id/candidates`：分页筛选候选题。
- `PATCH /admin/question-import-candidates/:id`：保存管理员修改和审核状态。
- `GET /admin/question-imports/:id/pages/:page`：鉴权后获取原始页预览。
- `POST /admin/question-imports/:id/confirm`：幂等地分批确认入库。
- `DELETE /admin/question-imports/:id/source`：提前删除允许清理的原件。

上传接口不等待解析完成。所有查询接口只返回管理员有权查看的数据，不返回提供商密钥、服务器路径或未经处理的内部错误堆栈。

## 14. 异常、安全和审计

### 14.1 异常恢复

- 单页、单行或单题失败不终止整个批次。
- 网络超时、限流和临时服务错误按指数退避自动重试。
- 每个失败项显示原因、定位和建议操作。
- 管理员草稿在刷新、重新登录和服务重启后仍可恢复。
- 服务重启后通过数据库状态继续任务。
- 提供商回调、轮询结果和确认请求都必须幂等。

### 14.2 安全

- 所有导入 API 同时验证登录身份和管理员角色。
- 原始文件及页面截图不使用公开静态 URL。
- 校验扩展名、MIME、文件签名、文件大小和页数或行数。
- 上传文件使用随机存储键，原文件名只作为元数据展示。
- XLSX 和 CSV 按纯数据处理，不执行宏、公式或脚本。
- 外部服务密钥只保存在服务器环境变量或密钥文件中。
- 发送给外部解析服务前，界面明确提示资料将由第三方服务处理。
- 日志不记录上传资料全文、题目全文、访问令牌或 API 密钥。

### 14.3 审计

记录以下操作：

- 上传、取消、重试和提前删除资料。
- 修改候选题、批量通过、忽略和改变重复处理策略。
- 分批确认、创建题目、创建版本和切换启用版本。
- 自动清理临时资源及清理失败。

审计项包含操作人、时间、动作、目标、结果和请求编号。

## 15. 保留、清理和备份

- 原始文件和临时解析产物默认在上传 30 天后清理。
- 若批次仍有待审核、需修改或解析失败的题目，到期时先提醒管理员，不静默删除原件。
- 未解决批次会占用临时存储配额；空间不足时阻止新上传并要求管理员处理，不删除仍需审核的原件。
- 已完成批次允许管理员提前删除原件。
- 清理任务每天执行一次，并在删除前重新检查候选题和正式资源引用。
- 正式题目引用的局部资源永久保留，随题目版本纳入文件备份。
- PostgreSQL 备份保存题目、版本、批次、资源索引和审计数据；永久文件资源使用独立备份流程。
- 提供商原始响应只用于 30 天内的审核和排错，不作为正式题目唯一数据来源。

## 16. 费用和运行保护

- 每个子任务记录提供商、页数、计费单位、估算费用和可获得的实际费用。
- 管理员任务页区分“预估费用”和“已确认费用”。
- 可以配置单批次费用上限和每月费用预警；达到上限时暂停新外部任务并等待管理员处理。
- OCR 回退只处理低质量页，不重复处理整个文档。
- 结构化服务优先使用确定性规则；若后期引入大模型，必须作为独立适配器记录模型、用量和费用，并继续要求人工确认。
- CPU、内存、临时磁盘和待处理任务数量设置上限。
- 导入任务使用低优先级并限制并发，确保学生功能优先。

## 17. 测试和基准

### 17.1 解析基准

使用三份有合法使用权的固定样本：

1. 普通文字版 PDF。
2. 扫描图片版 PDF。
3. 包含双栏、公式、表格和题图的复杂 PDF。

记录：

- 题目切分正确率。
- 题干和选项完整度。
- 答案、解析与题目匹配情况。
- 公式和图片保留情况。
- 需要人工修正的题目比例。
- 每 100 页的处理时间和费用。
- MinerU 默认结果及腾讯云 OCR 回退后的改善幅度。

在基准结果满足项目可接受标准前，只开放小型 PDF 测试，不开放整本资料导入。具体阈值由样本测试结果和管理员可接受的人工工作量共同确定，并记录在实施阶段的验收报告中。

### 17.2 自动化测试

覆盖：

- PDF、XLSX、CSV 上传校验和管理员权限。
- 文件签名、非法路径、超限文件和危险表格内容。
- 子任务拆分、状态汇总、重试、取消和服务重启恢复。
- 提供商适配器契约、低质量信号和 OCR 回退。
- 表格字段转换、知识点校验、公式和资源关联。
- 候选题部分确认、重复确认和并发确认。
- 确定重复、疑似重复和创建新版本。
- 学生历史记录继续引用旧版本。
- 原件到期清理、未完成批次保护和永久资源引用保护。
- PostgreSQL 集成测试、API 构建、Web 构建和生产镜像构建。

### 17.3 端到端验收

1. 普通学生和教师无法访问导入页面或文件接口。
2. 管理员上传三种格式并看到异步进度。
3. 一个失败页不会阻塞其他题目进入审核和正式题库。
4. 管理员可以在原始页旁修改题目、公式和图片。
5. 未经确认的候选题不会出现在学生练习中。
6. 重复题默认跳过，不会静默覆盖。
7. 更新题目产生新版本，历史答题仍展示原版本。
8. 重复点击确认只生成一次正式数据。
9. 临时原件清理后，正式题图仍可正常显示。
10. 导入任务运行期间，登录和答题保持可用。

## 18. 分阶段实施

### 阶段一：统一导入基础

- 导入批次、候选题、正式题目版本和资源数据模型。
- XLSX、CSV 模板、上传、校验、预览、查重和分批确认。
- 管理员任务列表、审核页面和审计记录。

### 阶段二：小型 PDF

- 私有 PDF 存储、页面预览和解析提供商适配器。
- MinerU 小型文档异步解析。
- 题目结构化、公式、图片和原页对照审核。
- 三类样本的首轮基准报告。

### 阶段三：整本资料

- 大 PDF 拆分和总体进度汇总。
- 失败页重试、腾讯云 OCR 回退。
- 费用统计、并发限制、磁盘配额和 30 天清理。

### 阶段四：质量优化

- 根据真实审核数据优化题目切分和质量阈值。
- 优化疑似重复排序、批量审核和快捷键。
- 评估腾讯云 COS 或离线解析工作节点，不改变上层审核模型。

阶段一应先提供稳定可用的表格导入；阶段二通过基准后再进入阶段三，避免在没有质量和成本数据时一次性开放整本 PDF。

## 19. 完成标准

- 管理员可以仅通过网站完成 PDF、XLSX 和 CSV 导入。
- 所有题目在正式入库前都经过明确的管理员确认。
- 部分失败不会阻塞正确题目分批入库。
- 重复题默认跳过，创建新版本时保留旧版本和历史作答。
- 公式、题图和原始页对照可用于审核，正式资源不会被临时清理误删。
- 原始文件默认保留 30 天，未完成批次不会被静默清理。
- 提供商密钥、原始文件和页面截图不公开暴露。
- 当前 2GB 生产服务器不运行大型本地模型，导入任务不会明显影响学生使用。
- 三类 PDF 样本已形成可复现的质量、耗时和费用报告。
- 自动化测试、PostgreSQL 集成测试和生产构建全部通过。
