# V3 产品重构验收标准（Sprint 0 基线）

> 本文件定义 V3 重构的完整验收标准，涵盖产品、技术、学习闭环三个维度。
> 每个 Sprint 完成后对照此标准逐项检查。

## D. 验收流程

### D1 每个 Sprint 结束时

1. 对照本文件运行对应 Sprint 的验收项（Sprint 1 检查 A1/A2/A3，Sprint 2 检查 A4/A5/B3，Sprint 3 检查 C 全部，Sprint 4 检查 A3/A4/A5 的 AI 子项）
2. 运行 `npm run build:shared && npm run build:api && npm run build:web` 确认构建通过
3. 运行 `npm test` 确认测试通过
4. 记录验收结果到 `docs/v3-refactor-log.md`
5. 合并到 `feature/v3-product-refactor` 分支

### D2 最终验收（Sprint 4 完成）

对所有 A/B/C 三类标准逐条运行验收，全部通过视为 V3 重构完成。

---

## E. 否决项

以下任一条件不满足，重构不可交付：

- 构建失败。
- 全量测试失败。
- 一位真人学生用户无法完成完整学习闭环（注册 → 诊断 → 今日任务 → 训练 → 错题 → 测试 → 次日新任务）。
- 掌握度数据在页面间不一致（如知识页与报告页对同一节点展示不同 mastery 值）。
