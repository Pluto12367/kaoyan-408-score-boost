## 架构变化

Contextual Coach 仍保持解释层定位：

```text
Projection Context
  -> ContextualCoachService
  -> AiTutorService
  -> LLM / template fallback
  -> response normalization
```

本 Sprint 完成：

- 统一 Contextual Coach response normalization。
- 对非法 JSON、空响应、类型错误、额外字段和 unsafe content 做安全处理。
- 增加 Prompt Guardrail，禁止模型虚构计划、任务、掌握度或复习状态变更。
- 增加四类 Context 和异常场景的 Evaluation Tests。
- 通过 structured logging 记录 source、fallbackReason、errorType、durationMs。
- 前端透明展示后端 source 与 fallbackReason，网络异常使用用户友好错误文案。

未修改：

- Student State 写入链路
- Recommendation Engine / RecommendationService
- StudyPlan、StudyTask、ReviewSchedule
- Prisma schema / migration
- Legacy Tutor API
- 前端主题在途文件
