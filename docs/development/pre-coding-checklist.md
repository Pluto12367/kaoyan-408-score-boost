# Pre-coding checklist

Use this checklist before changing code in this repository.

- [ ] I understand the requested behavior change or bug fix.
- [ ] I identified the files or modules likely to change.
- [ ] I searched 2-4 similar open-source projects, official examples, or mature docs.
- [ ] I captured useful patterns in `docs/development/open-source-reference-note-template.md` format, or in the task notes.
- [ ] I chose what to adopt and what to avoid.
- [ ] I have a verification plan before editing code.

If the task is documentation-only, read-only investigation, or running existing commands, the open-source reference check is optional.
