# 腾讯云公网 IP 体验版人工验收清单

> 适用范围：购买域名并启用 HTTPS 前的小规模封闭体验。每次正式发放邀请码前执行；测试账号与邀请码不得复用于其他网站。

## 公网访问

- [ ] 用桌面浏览器通过 `http://<公网 IPv4>` 打开首页，刷新和直接打开子页面均正常。
- [ ] 用手机蜂窝网络（关闭 Wi-Fi）访问同一地址，注册、登录和主要学习页面布局可用。
- [ ] 首页和 `/health` 正常，公网无法访问 3000、5432 或 Docker 管理端口。

## 邀请注册与会话

- [ ] 不填写邀请码或填写错误、过期、已停用的邀请码时，注册被拒绝且没有创建账号。
- [ ] 管理员创建一次性邀请码；新邮箱注册成功后自动登录。
- [ ] 同一邀请码第二次使用被拒绝。
- [ ] 用户退出后可用邮箱和密码再次登录；页面不得展示访问令牌或刷新令牌。

## 数据与账号管理

- [ ] 学生完成入门设置或一项学习任务，刷新浏览器后数据仍保留。
- [ ] 管理员停用学生账号后，旧会话失效且无法登录。
- [ ] 管理员恢复学生账号后，可再次登录且原学习数据仍存在。

## 重启、备份与恢复

- [ ] 执行 `docker compose --env-file .env.production -f compose.production.yml restart` 后，健康检查恢复，原账号可登录且学习数据仍在。
- [ ] 重启服务器后 Docker 自动拉起生产服务，健康检查、登录和数据持久化均正常。
- [ ] 手动执行备份，得到非空 `.dump` 和对应 `.sha256` 文件。
- [ ] 使用 `deploy/tencent-ip/verify-restore.sh <dump>` 完成隔离恢复；恢复过程没有连接或修改生产数据库。
- [ ] 确认最近 14 天备份存在，并把至少一份备份复制到服务器之外的受控位置。

## 防火墙与 HTTP 风险

- [ ] 腾讯云防火墙只向公网开放 TCP 80；TCP 22 仅允许管理员固定 IP/CIDR。
- [ ] TCP 3000、5432 和 Docker API 未开放；操作系统防火墙规则与云防火墙一致。
- [ ] 已告知体验用户：当前 HTTP 会暴露传输内容，不复用其他网站密码，不传真实隐私数据，仅限少量受邀用户短期测试。
- [ ] 购买域名后按部署手册配置证书和 443，80 重定向到 HTTPS，设置 `ALLOW_INSECURE_HTTP_IP=false` 并关闭旧 IP 入口。
