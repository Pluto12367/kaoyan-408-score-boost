================================================================================
🎯 项目目标
================================================================================

主要问题：
1. 深色主题文字对比度不足
2. 深色主题表单元素不可见
3. 深色主题卡片层次不清晰
4. 极简主题侧边栏区分度不足

优化目标：
1. 所有文字达到 WCAG AA 标准（对比度 ≥ 4.5:1）
2. 主要文字达到 WCAG AAA 标准（对比度 ≥ 7:1）
3. 表单元素清晰可见，易于交互
4. 卡片层次分明，视觉引导清晰
5. 侧边栏与内容区域有明显区分

================================================================================

================================================================================

目标 1：深色主题文字对比度不足
状态：✅ 已达成

目标 3：深色主题卡片层次不清晰
状态：✅ 已达成
详情：
  - --surface-soft: #182334 → #1c2a42 = +15%
  - --surface-soft-2: #1a2538 → #1e2e48 = +15%
  - 卡片层次分明

目标 4：极简主题侧边栏区分度不足
状态：✅ 已达成
详情：

  - 添加左侧 3px 高亮条
  - 侧边栏与内容区域明显区分

⚠️ 注意事项
================================================================================

设计决策：
1. 登录页不参与主题切换
   - 这是有意的设计决策
   - 登录页保持原有深色风格
   - 如果需要适配，取消 CSS 中的注释即可

2. 标准主题保持不变
   - 作为基准参考
   - 便于对比优化效果

3. 极简主题仅做微调
   - 保持极简风格
   - 仅增加侧边栏区分度

兼容性说明：
1. CSS 变量支持
   - 需要 IE 11+ 或现代浏览器
   - 不支持 CSS 变量的浏览器会忽略优化

2. 主题切换机制
   - 依赖 html[data-theme] 属性
   - 与现有主题系统完全兼容

3. 构建工具
   - 与 Vite 构建工具兼容
   - 无需额外配置
