# 学生体验任务说明

感谢你参与计算机考研 408 提分系统的封闭体验。本次体验主要想了解：这个系统是否真的能帮助你发现薄弱点、安排学习任务、复盘错题。

## 体验前

请准备 15-20 分钟，尽量按照真实备考状态体验，不需要刻意给好评。

## 体验任务

1. 打开体验链接，进入学生工作台。
2. 查看顶部指标：剩余天数、每日学习、预计提分、完成率。
3. 查看学习计划，判断任务是否符合你的当前备考阶段。
4. 查看 408 知识图谱，切换不同科目，观察薄弱点标记是否清楚。
5. 在题库训练中选择一道题，分别体验“答对/答错”的反馈。
6. 查看错题本，判断错因归类是否对复盘有帮助。
7. 查看提分报告，判断系统给出的薄弱点和建议是否有参考价值。
8. 切换到教研后台和管理看板，了解系统未来可能支持的老师/管理员功能。
9. 填写问卷。

## 反馈重点

请重点告诉我们：

- 哪个功能最像真实备考中会用到的工具？
- 哪个功能看起来有用，但现在还不够准确？
- 你希望它每天提醒你什么？
- 如果你愿意长期使用，还缺少什么能力？

本次体验仅用于产品改进。请不要在开放题中填写身份证号、准考证号、账号密码等敏感信息。
