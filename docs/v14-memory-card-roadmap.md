## 1. 内容生产轨（最紧迫——目录为空是唯一挡在价值前的缺口）

| 项 | 说明 | 治理属性 |
|---|---|---|
| 按考频×重要度排序产卡 | 优先高频节点（信号量 4 年 25 分、IEEE754 5 年 10 分等），内容投入对齐提分闭环 | 无需新 Gate（内容轨走既有 RULE-10 链） |
| 复用真题内容生产模式 | AI 草稿 → 具名互审 → 导入器；按章节/年份批次，每次会话机械重复（任务① 2009-2011 模式） | 同上 |
| 卡片质量规范成文 | 正面=可判定的问题/线索（禁陈述句笔记），背面=精确结论/公式；决定功能是「主动回忆」还是「划水翻页」 | DOC-ONLY |

## 2. 低风险产品增强（小任务粒度，各项独立可验证）

| 项 | 说明 | 治理属性 |
|---|---|---|
| 知识节点详情页入口 | 从「知识」分区节点抽屉直接复习该节点卡片（`knowledgeNodeId` 挂接已就绪） | 无需新 Gate，小 Design Gate 走形式 |
| 首页/今日简报到期数 | `到期 N 张` 只读信号进 Daily Brief。**只做展示**——自动建 StudyTask 属推荐行为，撞 Gate 15 | 只读部分无需 Gate |
| 会话内重现 | 本会话「没记住」的卡在队列尾部再出现一次（纯前端/纯函数策略） | 无需新 Gate |
| 到期堆积摊平 | 多日未学导致到期 > cap 20 被硬截；改按 retention 最差优先 + 每日配额摊平 | 无需新 Gate |
| 公式渲染（KaTeX） | 公式卡现为纯文本；Cache 映射/页表计算类 408 高频公式渲染价值高 | 无需新 Gate |
| teacher/admin 卡片管理面 | 目前仅脚本导入；**内容编辑对已复习学生状态的影响（改文本 vs 版本化）需要先定语义** | 小 Design Gate |

## 3. 证据与效果闭环（对齐 V13 主线，影子先行）

| 项 | 说明 | 治理属性 |
|---|---|---|
| 卡片→做题回流 | 卡片到期时附「做一道该节点题」入口——**卡片域合法连接能力域的唯一方式**（真实作答=强证据，走既有 practice 链自动进 canonical mastery） | 无需新 Gate（复用既有写路径） |
| 自评校准影子 | 对照「自评记住」vs 该节点后续真实作答正确率（沿用 `review-semantics.ts` 影子先例，非权威、不写表）。若证明自评系统性过乐观，才是调 4/2/0 映射的依据 | 无需新 Gate（影子） |
| 效果度量口径 | 可声明：使用量（OBSERVED）、卡片保持率（DERIVED）；成绩影响 = UNAVAILABLE，禁止任何 Verified 声明（RULE-11） | 持续约束 |
