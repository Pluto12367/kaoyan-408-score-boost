# 管理员题库文档导入手册

题库导入仅限管理员。先下载 CSV/XLSX 模板；CSV 使用 UTF-8（可带 BOM）。表头包括：`科目`、`章节`、`知识点`、`题型`、`难度`、`题干`、`选项 A`、`选项 B`、`正确答案`、`答案解析`、`来源`、`年份`、`建议答题时间（秒）`。题型只允许 `选择题`、`综合题`、`判断题`，难度只允许 `基础`、`中等`、`困难`。选择题应提供可判定的答案和选项；每条记录都必须有来源。

上传 PDF 前，确认你有处理该材料的权利，并在“来源”中留下可审计说明。不要上传整本教材、试卷合集或含个人信息的材料。PDF 解析服务会产生费用；优先使用少页、小批次试运行。上传后查看批次进度及每个失败页，可只重试失败任务。请求失败时保留页面显示的请求 ID，并一同提供给运维人员；不要附上文件、令牌或题干全文到工单。

在审核页逐题对照原始页。尤其检查公式 LaTeX、图片裁剪范围、跨页题目、答案与解析的归属。对疑似重复题选择：

- `跳过`：不创建题目；
- `新建`：保留为新的题目族；
- `新版本`：替换同一题目族的当前版本，历史学习记录仍关联旧版本。

可以先确认审核完成的一部分题目；未确认项会留在批次中。确认操作有幂等保护，重复点击不会重复创建题目。临时原文件、页面预览和未提升资源最多保留 30 天；确认后需要保留的图片会转为永久资源。留意“存储空间不足”提示，停止继续上传并联系运维。

## PDF 凭据

MinerU 与腾讯 OCR 凭据只能写入服务器的 `.env.production` 或批准的测试环境密钥：`MINERU_API_TOKEN`、`TENCENTCLOUD_SECRET_ID`、`TENCENTCLOUD_SECRET_KEY`、`TENCENTCLOUD_REGION`。不要提交 `.env.production`，不要放进 CSV、截图、聊天记录或浏览器控制台。未配置 MinerU 时，PDF 导入会安全失败，Excel/CSV 导入仍可用。
