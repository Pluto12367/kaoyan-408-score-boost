# 邀请码与账号管理

本系统采用邀请制注册。学生必须使用管理员发放的邀请码注册；教师和管理员由管理员在后台创建。

## 创建学生邀请码

1. 使用管理员账号登录。
2. 进入管理工作区的“邀请码管理”。
3. 填写批次名称、可用次数和过期时间。
4. 点击“创建邀请码”。
5. 立即复制完整邀请码并发给学生。

完整邀请码只在创建成功后显示一次。后续列表只显示前缀、批次名称、使用次数、过期时间和状态。

## 停用邀请码

在“邀请码管理”列表中点击“停用”。停用后，新学生不能再使用该邀请码注册；已注册账号不受影响。

## 停用和恢复学生账号

在“用户管理”中找到学生，点击“停用账号”。停用会立即撤销该学生的刷新令牌，并拒绝后续登录、刷新和学习接口访问。

需要恢复时，点击“恢复账号”。恢复不会自动恢复旧会话，学生需要重新登录。

## 临时密码

点击“临时密码”会生成一次性临时密码。请立即复制并发给对应用户。

用户使用临时密码登录后，必须先修改密码；在完成改密前，系统不会加载学习工作区。改密成功后，临时密码失效，用户使用新密码继续登录。

## 教师和管理员账号

在“教师与管理员”面板创建内部账号。该入口只允许创建教师或管理员，不用于创建学生。学生账号必须通过邀请码注册。
